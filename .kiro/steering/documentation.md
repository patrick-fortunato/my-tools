# Documentation Maintenance

Every time a code change is made to the application, the following documentation files must be updated to reflect the change:

- `README.md` — Project overview, structure, commands, API reference
- `.kiro/specs/developer-tools-expansion/requirements.md` — Feature requirements
- `.kiro/specs/developer-tools-expansion/design.md` — Architecture and design decisions
- `.kiro/specs/developer-tools-expansion/tasks.md` — Task completion status

This includes but is not limited to:
- Adding or removing tools/features
- Changing file structure or naming
- Modifying API endpoints or controllers
- Updating dependencies
- Changing themes or UI patterns
- Refactoring services, models, or architecture patterns

Do not wait to be asked — update documentation as part of every change.
